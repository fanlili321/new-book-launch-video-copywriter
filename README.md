# 新书首发视频文案生成 Skill

面向银行螺丝钉新书上市宣发的 Codex Skill。它把已确认的公众号首发文章转换为适合真人口播的首发视频文案，并支持写入飞书、根据老板最终稿复盘，以及持续沉淀系列写作经验。

## 适用场景

- 根据新书公众号首发文章生成首发宣传视频文案
- 参考历史确认稿，延续系列结构和品牌口吻
- 将确认稿新建或更新到指定飞书文件夹
- 对照初版与老板最终版，总结可复用修改规律

普通短视频选题、直播大纲和非银行螺丝钉书籍营销不属于本 Skill 的默认范围。

## 核心能力

- 完整读取飞书 Docx/Wiki 正文、批注和历史修订版本
- 以本次公众号文章为事实底稿，避免误用旧书数据
- 默认将视频正文控制在约 850–900 个中文字符，并在交付前实测
- 采用“现实感受与数据 → 用户矛盾 → 产品解释 → 核心疑问 → 本书能力 → 适合人群 → 主题金句”的口播结构
- 区分文章信息和视频信息，通常剔除二维码、福利细则、读后感活动等销售操作内容
- 从老板最终版本中提炼稳定规则，不把单次措辞误判成通用要求

## 文件结构

```text
new-book-launch-video-copywriter/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── style-and-review.md
```

- `SKILL.md`：触发范围、工作流程、飞书交付和检查标准
- `references/style-and-review.md`：历史确认稿与老板最终稿验证出的风格规则
- `agents/openai.yaml`：Codex 界面名称、默认提示词和自动触发设置

## 使用方式

可以直接描述任务，让 Codex 自动识别；也可以显式调用：

```text
使用 $new-book-launch-video-copywriter，根据这篇已确认的公众号首发文章生成新书首发宣传视频文案。
```

建议输入：

1. 本次新书已确认的公众号文章或飞书链接；
2. 可参考的历史确认稿；
3. 如需写入飞书，提供目标文件夹；
4. 如需复盘，提供老板最终版或对应历史修订文档。

## 设计原则

好的新书首发视频稿不是简单缩短公众号文章。它应把有限篇幅优先分配给数据、场景、用户判断和记忆点，减少目录式介绍与通用表达。

未经用户确认，Skill 不会擅自把文档标记为“已确认”，也不会写入或修改飞书文档。
